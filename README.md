# 晨雾监测系统

基于 React、Vite 与 Tailwind CSS 构建的晨雾监测平台，可为指定地点评估日出前后晨雾 / 平流雾发生概率，并提供摄影关键时段、逐小时气象指标与云层剖面可视化。

## 核心功能

- **晨雾 / 平流雾概率预测**：综合相对湿度、温度-露点差、风速与温度趋势等指标，输出 0-100% 的启发式概率并给出触发条件说明。
- **日出与摄影时段**：使用天文算法计算日出、蓝调时刻（-30 至 +20 分钟）与金色时刻（-10 至 +60 分钟），交互式时间轴呈现。
- **逐小时气象表格**：展示日出前后 2 小时内的温度、湿度、露点、风速、云量及天气编码，并对高湿度、微风等关键条件高亮。
- **云层剖面图**：以分层面积图呈现日出前后 1 小时内低/中/高云量的变化趋势，并提示当前高度基于海平面。
- **地点配置**：支持自定义地点名称与 WGS-84 经纬度，配置保存至浏览器 localStorage。
- **算法说明**：独立页面详细描述雾预报公式、日出计算流程、交互式可视化设计及未来改进方向。

## 技术栈

- 前端：React 19、TypeScript、Vite、Tailwind CSS、shadcn 风格组件（自定义样式）、Recharts、Lucide Icons。
- 数据：Open-Meteo Forecast API（1 小时分辨率）。

## 快速开始

```bash
pnpm install
pnpm run dev
```

访问 `http://localhost:5173` 查看应用。默认监测地点为西安丈八一路（34.207013°N, 108.860019°E），可在页面顶部修改。

## 可用脚本

| 命令            | 说明                       |
| --------------- | -------------------------- |
| `pnpm run dev`  | 启动开发服务器（含 HMR）。 |
| `pnpm run build`| 生成生产环境构建。         |
| `pnpm run preview` | 预览构建产物。          |

## 部署说明

项目支持容器化部署，推荐通过 Docker Compose 启动前端与 Nginx。构建步骤如下：

```bash
pnpm install
pnpm run build
```

将 `dist/` 目录交由 Nginx 或静态资源服务器托管即可。未来可根据需要加入后端 API 或缓存策略。

## 数据与算法局限

- 模型基于启发式规则，适合摄影/观测决策参考，不等同于气象部门预报。
- 未考虑地形、地表类型及实际海拔，高程修正在计划中。
- Open-Meteo 数据为 1 小时分辨率，无法捕捉分钟级别的突变。
- 更精确的云底/云顶高度可通过额外 API 接入。

欢迎根据实际场景继续扩展功能，例如集成海拔 API、历史雾日统计或移动端自适应优化等。
